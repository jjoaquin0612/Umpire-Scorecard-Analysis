# MLB Umpire Scorecard Analysis 
**Author:** Jack Joaquin, Bridgewater State University   

This repository is a semester-long data mining project that evaluates MLB home-plate umpire performance using game-level data downloaded from [umpscorecards.com](https://umpscorecards.us/data/umpires). It groups umpires into performance tiers, flags unusually poor games, and examines how umpire accuracy relates to how often calls are challenged under the 2026 automated ball-strike challenge system.

Each folder represents a different area of analysis I conducted within the dataset. 

## Umpire Analysis  
The `UmpireAnalysis` folder focuses on every umpire's calling quality, accuracy, and consistency relative to their calculated expectations during the seasons 2018-2026, in every stadium that held an MLB game. The following bullets are other mining questions that will be answered within this folder:
- Which team performed best and worst behind each umpire at home plate?
- Are umpires performing better in the Postseason?
- Are umpires getting better each season?
- Do umpires demonstrate bias towards home teams
- Has the expectancy of correct calls for umpires gotten higher? (Is MLB expecting too much from their umpires?)
